# GSRT-HALO-Corrected
A pathway out of the ER–police–shelter cycle: street-level intake, an honest Choice Point, a 3-month peer-run MASH Antifragile recovery camp alongside medical care, then paid work at GSRT Earthworks. Includes the costed model ($7,500/stay), evidence trail, ROI workbook and intake prototype. Modelled figures, not pilot data.
